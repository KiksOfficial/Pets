# Veebilehest

Oleme loomas interaktiivset veebilehte, mille eesmärk on leevendada igavust. Platvorm ühendab endas kolm peamist moodulit: avalehel asuva Pou-stiilis virtuaalkassi hoolitsemismängu, Plinko mini-mängu toidu teenimiseks ning foorumi, kus kasutajad saavad omavahel suhtleda ja selgitada välja kõige nunnuma kassi.

Tiim:

Marcus Ariston Kikerpill – Virtuaalkass ja avaleht

Rivo Pruus – Plinko mini-mäng

Egert Kerve – Foorum ja kasside hindamine
